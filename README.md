# 📊 Gerador de Gráficos

Uma aplicação desenvolvida em Python para geração de gráficos a partir de dados e análises, com foco em visualização clara, moderna e intuitiva.

O projeto foi criado para facilitar a interpretação de informações através de representações gráficas dinâmicas e organizadas.

## 📌 Sobre o Projeto

O Gerador de Gráficos permite transformar dados em gráficos visuais de maneira prática e rápida apenas com o link do arquivo excel.

A aplicação pode ser utilizada para:

Visualização de dados
Análises simples
Relatórios
Estudos
Dashboards básicos

Tudo isso através de uma interface moderna e amigável.

## 🚀 Objetivo

O principal objetivo do projeto é fornecer uma ferramenta simples para criação de gráficos enquanto aprimora conhecimentos em:

- Python

- Manipulação de dados

- Visualização gráfica

- Interfaces gráficas

- Organização de projetos

## 📦 Instalação

Clone o repositório:

git clone https://github.com/GabrielaSouzaDev/grafico.git

Entre na pasta do projeto:

cd grafico

Instale as dependências:

pip install pandas

pip install openpyxl

pip install matplotlib

pip install customtkinter


## ▶️ Como Executar

Execute o arquivo principal:

python grafico.py
